# FERRONACHT — versión web

Versión web de pruebas de FERRONACHT (puesto de mando ferroviario, CTC).
Aquí solo está el juego compilado; el código está en otro repositorio privado.

**Jugar:** https://eterniitty.github.io/FERRONACHT-web/

## En el iPhone o iPad como app
1. Abre el enlace en **Safari**.
2. Pulsa **Compartir** → **Añadir a pantalla de inicio**.
3. Ábrelo desde el icono: pantalla completa y funciona sin conexión tras la primera carga.

Requiere Safari 16.4 o posterior.
